Capturas do protótipo HTML, uma por ecrã. Servem de referência visual para a implementação descrita em `FLUXO-SPEC.md`. Onde uma captura e a spec discordem, a spec manda.

Desktop a 1440px, mobile a 390px. Todas a 2x.

Todos os dados são fictícios. A entidade "Escola Nova" não existe. Os identificadores de base e tabelas são exemplos.
