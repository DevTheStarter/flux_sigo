# Fluxo · pacote para implementação

Ler por esta ordem.

1. `FLUXO-SPEC.md` — a especificação. É a única fonte de verdade.
2. `mockups/README.md` — índice das capturas de ecrã, com a secção da spec a que cada uma corresponde.
3. `mockups/*.png` — 39 capturas, desktop, escuro e mobile.
4. `prototipo/fluxo.html` — protótipo interativo. Abrir num browser para ver animações e transições. É referência, não código a reutilizar: reconstruir em Next.js.
5. `docs/` — documentos legais. Não são de desenvolvimento, mas o separador Privacidade e o download do contrato têm de bater certo com as secções 8.3 e 9 da spec.

Onde a spec e o protótipo discordem, a spec manda.
